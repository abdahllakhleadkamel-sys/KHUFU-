# خوفو KHUFU

مشروع Flutter تجريبي كبداية لتطبيق خوفو.

## تشغيل المشروع
1. ثبّت Flutter وAndroid Studio.
2. افتح مجلد المشروع في محرر يدعم Flutter.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```

## بناء APK
بعد إضافة مجلد Android الخاص بمشروع Flutter وتشغيل بيئة البناء:
```bash
flutter build apk --release
```
